# Neon Snake: Knightfall

Futuristic Snake game with arcade mode, story mode, skins, responsive layout, and a server-backed leaderboard.

## Start

```bash
npm start
```

Then open:

```text
http://localhost:3000
```

The leaderboard is saved in `leaderboard.json` on the server. For a public release, deploy the folder to a Node-compatible host such as Render, Railway, Fly.io, or a VPS.
